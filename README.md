Tools: Unreal Engine v5.0 and Visual Studio 2019 Community

Build and compile using Unreal Engine v5.0+

##movement
With the keyboard and mouse: W A S D to move, press and hold LPM to pick up items, mouse to look around

##CryptRaider is a puzzle-adventure game set inside a mysterious tomb filled with hidden mechanisms, locked passages and forgotten secrets
Your mission is to explore the crypt, solve environmental puzzles and uncover the mystery buried deep within tomb. Player must interact with objects, carry and place items in specific locations.
